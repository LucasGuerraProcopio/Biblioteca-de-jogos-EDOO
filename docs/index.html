Biblioteca de Jogos

Uma loja e biblioteca de jogos escrita em C++ para praticar orientação a objetos. Dá para navegar pelo catálogo, criar uma conta, colocar dinheiro na carteira, comprar, instalar, jogar e pedir reembolso. Tudo fica salvo em um banco SQLite.

O que dá para fazer

As mesmas funções existem no menu do terminal e na interface do navegador. Os dois usam as mesmas classes e o mesmo banco de dados.

Minha conta e biblioteca

Cada conta tem saldo, cartões e uma biblioteca com os jogos que adquiriu. Na biblioteca dá para instalar, desinstalar, registrar horas jogadas e pedir reembolso.

O reembolso segue regras: até 14 dias depois da compra e com menos de 2 horas jogadas. O dinheiro volta para onde saiu, saldo ou cartão.

Carteira

O saldo entra por depósito via pix, com taxa de 2%, ou por gift card, que só pode ser resgatado uma vez.

Cartões de crédito têm limite, e por segurança só os 4 últimos dígitos são guardados. O CVC nunca é salvo, e as senhas das contas são guardadas com hash.

Administração

CRUD completo dos jogos: cadastrar, listar, editar e remover. Um jogo que está na biblioteca de alguma conta não pode ser removido.

Também é por aqui que se criam gift cards e se removem contas, sempre com a senha da conta.

Contas

Criar conta e entrar com nome e senha. Nome ou senha errados recebem a mesma mensagem, para não revelar quais contas existem.

Como funciona por dentro

Toda a lógica fica nas classes em C++. A interface do navegador só mostra os dados e envia os pedidos.

  1. Navegador

    HTML, Tailwind e JavaScript. Mostra as telas e chama a API.

  2. Servidor local

    servidor.cpp com cpp-httplib. Recebe pedidos como /api/comprar e responde em JSON.

  3. Classes em C++

    Catálogo, contas, pagamentos e regras. As mesmas usadas pelo menu do terminal.

  4. Banco SQLite

    biblioteca.db guarda jogos, contas, bibliotecas, cartões e gift cards.

As mensagens que as classes escrevem com cout aparecem no painel "Mensagens" da tela. Isso é feito pela classe captura_cout, sem mudar nenhuma das outras classes.

Orientação a objetos no código

Onde cada conceito da disciplina aparece no projeto.

Conceito Como aparece
Classe abstratajogo_base tem GetPreco() e EhPago() como funções virtuais puras, então não existe um "jogo genérico".
Herançajogos_gratuitos e jogos_pagos herdam de jogo_base. pagamento_saldo e pagamento_cartao herdam de forma_de_pagamento.
PolimorfismoO catálogo guarda tudo como jogo_base*, e cada chamada de GetPreco() executa a versão da classe real. Os métodos sobrescritos usam override.
EncapsulamentoAtributos private e protected, acessados por getters e setters. A senha nunca sai da classe: só é conferida com verificar_senha().
Sobrecarga de operadores<, > e == em jogo_base. O < ordena o catálogo por tamanho.
Padrão Strategyforma_de_pagamento define como pagar e estornar. A compra não sabe se o dinheiro sai do saldo ou do cartão.
Padrão Repositorycatalogo e repositorio_usuarios concentram a busca, o cadastro e o salvamento dos objetos no banco.
Memória e RAIIDestrutores liberam os ponteiros, e a cópia é proibida com = delete para evitar double free. captura_cout desvia o cout no construtor e devolve no destrutor.

Rodar no seu computador

Funciona em Windows, Linux e macOS. Só é preciso o compilador g++: o SQLite e o cpp-httplib já vêm no projeto.

  1. 1

    Baixe o projeto e entre na pasta.

    git clone https://github.com/LucasGuerraProcopio/Biblioteca-de-jogos-EDOO.git
cd Biblioteca-de-jogos-EDOO
  2. 2

    Compile o SQLite, só na primeira vez.

    gcc -c códigos/sqlite3.c -o sqlite3.o
  3. 3

    Compile e rode a interface, com o comando do seu sistema.

    Windows (PowerShell)

    g++ -std=c++11 -D_WIN32_WINNT=0x0A00 códigos/servidor.cpp sqlite3.o -lws2_32 -o servidor.exe
.\servidor.exe

    Linux

    g++ -std=c++11 códigos/servidor.cpp sqlite3.o -ldl -lpthread -o servidor
./servidor

    macOS

    g++ -std=c++11 códigos/servidor.cpp sqlite3.o -o servidor
./servidor
  4. 4

    Abra http://localhost:8080 no navegador.

Os comandos de cada sistema, o menu no terminal e as soluções para problemas comuns estão no README do repositório.
